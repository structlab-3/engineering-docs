# 第5章 总结与展望


## 5.1 全文总结

主动噪声控制技术通过产生与初级噪声幅值相等、相位相反的次级声波实现噪声抵消，在低频噪声控制领域具有独特优势。传统的滤波-x最小均方算法基于高斯噪声假设和均方误差准则设计，在实际应用中面临的噪声环境往往包含脉冲成分。工业设备的冲击噪声、交通工具的间歇性突发噪声以及电子设备的电磁干扰脉冲都属于这类非高斯噪声，脉冲噪声的统计特性服从重尾分布，具有方差无限或不存在的特点，导致基于二阶统计量的传统算法性能严重下降甚至完全失效。脉冲噪声中的离群值幅值可能是正常信号的数十倍甚至上百倍，这些极端值在梯度计算中产生过大的扰动，使自适应滤波器权重向量发生剧烈振荡，破坏算法的收敛过程。针对脉冲噪声环境，已有研究提出多种改进算法，基于符号函数的FxLMP算法计算简单但性能有限，基于阈值限幅的ThFxLMS算法的阈值选取缺乏自适应性，基于M估计器的FxLMM算法仅对误差信号进行保护而忽略参考信号和权重向量的保护，MFxLMM算法增加参考信号保护但在极强脉冲环境下仍可能出现权重发散，基于权重约束的CFxLMS算法的硬限幅约束在阈值处产生截断失真。这些算法从不同角度对脉冲噪声进行抑制，取得一定效果，但仍存在性能不足或结构复杂等问题。

本文的主要贡献体现在两个方面。在算法增强层面，提出基于M估计器的滤波器系数限制滤波-x最小平均M估计算法EMCFxLMM。该算法在MFxLMM算法基础上增加基于M估计器的权重软约束机制，通过在误差信号、参考信号和滤波器权重三个层面应用M估计器保护，形成对脉冲噪声的三重防御体系。误差信号M估计器限制梯度方向的异常扰动，参考信号M估计器控制权重更新步长的幅值，权重M估计器防止滤波器系数的累积过冲。三层保护相互配合使算法在各种脉冲强度下都能保持稳定运行，权重M估计器采用L1范数作为约束对象，通过Hampel M估计器的非线性变换实现对权重向量的自适应软约束，避免传统硬限幅方法的截断失真，使权重调节过程平滑连续。算法所需的所有M估计器阈值参数均通过在线估计方法获得，采用指数加权移动平均估计均值、滑动窗中值滤波估计方差，无需先验信息或离线调试，增强工程实用性。仿真实验表明，EMCFxLMM算法在α=1.6、1.4和1.2三种脉冲强度环境下的稳态降噪量分别达到-14.62 dB、-6.18 dB和-3.47 dB，相比MFxLMM算法分别提升1.78 dB、1.91 dB和2.51 dB，平均稳态降噪量-8.09 dB，收敛速度12267次迭代。

在算法简化层面，提出增强型滤波-x符号变换最小平均M估计算法EMFxSLMS。该算法采用符号函数对误差信号进行二值化处理，对参考信号采用M估计器进行非线性变换，形成"符号变换+M估计器"的混合保护机制。符号变换通过消除误差信号的幅值信息从根本上防止误差离群值的过度影响，计算复杂度极低仅需一次符号判断运算。参考信号M估计器通过压缩参考信号的离群值防止权重更新步长过大，EMFxSLMS算法无需权重约束，结构更加简洁，相比EMCFxLMM算法计算复杂度降低约40%。在算法简化层面，提出增强型滤波-x符号变换最小平均M估计算法EMFxSLMS。该算法采用符号函数对误差信号进行二值化处理，对参考信号采用M估计器进行非线性变换，形成'符号变换+M估计器'的混合保护机制。实验验证了符号变换的极端归一化特性在脉冲噪声环境下能够达到甚至超越多层M估计器保护的性能。在α=1.6、1.4和1.2环境下的稳态降噪量分别达到-16.81 dB、-14.03 dB和-9.78 dB，平均稳态降噪量-13.54 dB，相比EMCFxLMM算法提升5.45 dB，收敛速度快18%。这一发现表明符号变换的极端归一化特性在脉冲噪声环境下比M估计器的渐进式压缩更加有效，为脉冲噪声主动控制算法设计提供新的思路。两种算法的设计思路体现不同的技术路线，EMCFxLMM算法追求多层次的精细化保护，通过三重M估计器机制实现全方位的脉冲抑制；EMFxSLMS算法则采用极简主义设计理念，用最少的计算资源实现最强的鲁棒性。两种算法的成功验证脉冲噪声主动控制算法设计既可以通过增加保护层次来提升性能，也可以通过简化结构来获得性能提升，关键在于根据脉冲噪声的统计特性选择合适的非线性变换方法。


## 5.2 未来展望

本文提出的EMCFxLMM和EMFxSLMS算法在脉冲噪声主动控制中取得显著成果，但仍有诸多方向值得进一步研究。在算法理论方面，本文主要通过仿真实验验证算法的有效性，对算法收敛性的理论分析仍不够深入，特别是多重非线性变换对算法收敛轨迹的综合影响机制尚未完全揭示。借助随机逼近理论、Lyapunov稳定性理论等数学工具可以对算法的收敛条件、收敛速度和稳态性能进行更严格的理论分析，建立脉冲强度、M估计器参数、步长因子与算法性能之间的定量关系。符号函数在脉冲噪声环境下表现出的优异性能背后的数学机理值得深入探讨，为什么极端的幅值归一化反而优于渐进式的非线性压缩，这一现象与脉冲噪声的α稳定分布特性之间存在何种内在联系，这些问题的理论解答将为算法设计提供更坚实的数学基础。

在算法优化方面，变步长策略与M估计器的结合值得探索，根据误差信号和参考信号的统计特性自适应调整步长因子，在算法启动阶段采用较大步长加快收敛，在稳态阶段采用较小步长降低失调，进一步提升算法的综合性能。M估计器阈值参数的自适应优化方法也有研究价值，根据脉冲强度的实时变化动态调整阈值，使算法在不同噪声环境下都能保持最优性能。Huber、Tukey和Andrews等其他类型的M估计器在脉冲噪声环境下的性能差异对比，可以为不同应用场景选择最合适的M估计器提供依据。EMFxSLMS算法虽然在三种测试场景下均表现最优，但在极强脉冲环境下仍存在一定的性能波动，如何在保持符号函数低复杂度优势的同时进一步提升稳定性，是值得研究的方向。

在应用拓展方面，本文算法在单通道前馈式主动噪声控制系统中得到验证，多通道系统、反馈式系统和混合式系统中的应用推广需要研究多通道情况下的权重约束策略和计算复杂度优化方法。主动耳机、车辆主动降噪系统、管道噪声控制系统等实际应用场景可以验证算法在真实环境中的性能并针对实际应用的特殊需求进行针对性优化。主动耳机应用需要考虑头部运动对声学通道的影响，车辆降噪需要处理多噪声源的干扰，管道噪声控制需要考虑声传播的时延特性，这些实际约束条件都对算法提出新的挑战。

在硬件实现方面,算法在数字信号处理器、现场可编程门阵列等硬件平台上的高效实现方法有待深入探索。定点化、流水线并行、查找表优化等技术可以降低算法的计算开销和功耗，使算法能够在资源受限的嵌入式系统中实时运行。EMFxSLMS算法的低复杂度特性使其特别适合硬件实现，符号函数运算可以通过简单的比较器实现，参考信号M估计器的评分函数可以通过查找表存储，这些优化措施将进一步降低硬件成本和功耗。推动脉冲噪声主动控制技术从理论研究走向工程应用，为改善人类生活和工作环境中的噪声污染问题做出贡献。
