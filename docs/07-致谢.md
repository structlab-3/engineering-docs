# 致谢

时光荏苒，三年的硕士研究生生活即将画上句号。从初入校门的懵懂到如今能够独立完成这篇学位论文，这段经历让我收获颇丰。本论文的完成离不开李晨老师的悉心指导。从选题开始，李晨老师就帮我理清思路，确定研究方向。文献调研时遇到困惑，导师总能一针见血地指出问题所在。算法设计过程中的每一次卡壳，仿真实验里的每一个异常结果，李晨老师都耐心地和我一起分析原因、寻找解决办法。论文初稿完成后，导师花了大量时间帮我修改，小到公式推导的细节，大到整体框架的调整，让我对主动噪声控制技术有了更深的理解。李晨老师严谨的治学态度和务实的科研精神将使我终身受益。实验室的师兄师姐们也给了我很多帮助，课题组的讨论让我开阔了视野，调试代码时的交流让我少走了许多弯路。图书馆的自习时光、实验室通宵调试程序的夜晚、答辩前反复修改PPT的日子，这些经历都将成为珍贵的回忆。感谢母校提供的学习环境和实验条件，让我能够顺利开展研究工作。由于个人水平有限，论文中难免存在疏漏和不足，恳请各位老师批评指正。
