# 第4章 增强型滤波-x符号变换最小平均M估计算法


## 4.1 引言

上一章提出的EMCFxLMM算法通过三重M估计器保护机制在脉冲噪声环境下获得优异性能，但算法的计算复杂度相对较高，在某些计算资源受限的应用场景中可能存在实时性问题。为探索更高效的脉冲抑制方案，本章提出一种基于符号变换的脉冲噪声主动控制算法。符号函数作为一种极简的非线性变换，仅保留信号的符号信息而完全舍弃幅值信息，具有计算复杂度极低的优势。符号变换通过将误差信号映射为±1，理论上对脉冲幅值具有完全免疫特性，这种极端归一化机制在强脉冲环境下可能展现独特优势。本章将验证符号变换在脉冲噪声主动控制中是否能够达到甚至超越多层M估计器保护的性能。基于这一研究思路，提出增强型滤波-x符号变换最小平均M估计算法（EMFxSLMS），该算法采用符号函数对误差信号进行二值化处理，对参考信号仍采用M估计器进行非线性变换，形成"符号变换+M估计器"的混合保护机制。EMFxSLMS算法无需对滤波器权重进行约束，结构简洁，相比EMCFxLMM算法计算复杂度降低约40%。算法所需的参考信号M估计器阈值参数通过在线估计方法获得，保持良好的工程实用性。

## 4.3.2 计算复杂度分析

EMFxSLMS算法相比EMCFxLMM算法的主要优势在于计算复杂度的显著降低。分析EMFxSLMS算法的计算复杂度，并与EMCFxLMM算法和其他经典算法进行对比，EMFxSLMS算法的主要计算步骤包括滤波器输出计算、误差信号计算、符号变换、滤波参考信号生成、参考信号M估计器运算、参考信号统计估计和权重向量更新等。滤波器输出信号的计算需要L次乘法和L−1次加法。滤波参考信号的计算需要M次乘法和M−1次加法。误差信号e[n]=d[n]−y[n]的计算需要1次减法。误差信号符号变换sign(e[n])仅需1次符号判断运算，相比误差M估计器的计算量（1次除法、3次比较、2次乘法）显著降低。参考信号M估计器运算需要对L个参考信号元素分别执行标准化和评分函数计算，共需L次除法、3L次比较和2L次乘法。权重向量更新需要L次乘法和L次加法。参考信号统计估计包括均值更新、方差更新和中值计算，计算量与EMCFxLMM算法中的参考信号统计估计相同。综合上述各计算步骤，EMFxSLMS算法每次迭代所需的主要计算量为：乘法运算次数约为M+3L+6+Nx，加法运算次数约为M+3L+4+Nx，比较运算次数约为3L+1，除法运算次数约为L，中值计算需要O(logNx)复杂度。与EMCFxLMM算法相比，EMFxSLMS算法省去误差信号统计估计、误差M估计器运算、权重L1范数计算、权重统计估计和权重M估计器约束等计算步骤，总计算量降低约40%。各算法的计算复杂度对比清晰展示EMFxSLMS算法的计算效率优势，如表4.1所示。
