## 研究概述

### 核心问题

传统主动噪声控制(ANC)算法在脉冲噪声环境下性能急剧下降甚至完全失效，因为：
- 脉冲噪声服从重尾分布，方差无限或不存在
- 离群值幅值可达正常信号的数十倍
- 传统FxLMS算法基于高斯噪声假设和均方误差准则

### 提出的解决方案

本论文提出两种基于M估计器的脉冲噪声主动控制算法：

#### 1. EMCFxLMM算法
**增强型基于M估计器的滤波器系数限制滤波-x最小平均M估计算法**

- **三重M估计器保护体系**
  - 误差信号M估计器
  - 参考信号M估计器
  - 权重M估计器（L1范数软约束）

- **性能表现**
  - α=1.6: -14.62 dB
  - α=1.4: -6.18 dB
  - α=1.2: -3.47 dB
  - 平均收敛时间: 12267次迭代

#### 2. EMFxSLMS算法 ⭐ 最优
**增强型滤波-x符号变换最小平均M估计算法**

- **混合保护机制**
  - 符号函数处理误差信号（二值化）
  - 参考信号M估计器

- **性能表现**（在所有测试场景下最优）
  - α=1.6: -16.81 dB
  - α=1.4: -14.03 dB
  - α=1.2: -9.78 dB
  - 平均稳态降噪量: -13.54 dB
  - 平均收敛时间: 10033次迭代
  - 相比EMCFxLMM提升5.45 dB，收敛速度快18%
  - 计算复杂度降低约40%

### 关键创新点

1. **三重M估计器协同保护机制** - 在误差、参考信号和权重三个层面同时应用M估计器
2. **基于L1范数的权重软约束** - 避免传统硬限幅的截断失真
3. **符号变换与M估计器混合保护的理论验证** - 验证了极简的二值化处理优于复杂的渐进式压缩
4. **参数完全在线估计** - 所有阈值参数无需先验信息或离线调试
5. **计算复杂度与性能的优化平衡** - 证明性能优化并非必然以复杂度为代价

### 主要结论

- **EMFxSLMS算法**在所有测试场景下表现最优
- 符号变换的极端归一化特性在脉冲环境下优于M估计器的渐进式压缩
- 脉冲噪声控制算法设计可通过两种路径：
  - 路径1：增加保护层次（EMCFxLMM）
  - 路径2：简化结构+极简非线性变换（EMFxSLMS，性能更优）
